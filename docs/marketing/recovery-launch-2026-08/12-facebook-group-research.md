# Human qualification checklist for every candidate

Before setting a group to `ELIGIBLE`:

- [ ] Confirm the group still exists and is active.
- [ ] Confirm the audience includes parents/students of secondary-school age where relevant.
- [ ] Read the full group rules.
- [ ] Check whether promotional links are banned, allowed, limited to specific days, or require admin approval.
- [ ] Search inside the group for `ripetizioni`, `debito`, `recupero`, `inglese`, `pubblicità`, `promozione`, `link` where the UI allows it.
- [ ] Check whether similar educational resources are posted legitimately.
- [ ] If promotion is restricted to a thread/day, record the exact allowed slot.
- [ ] Do not post if rules are unclear and the group is a sensitive support/community space.
- [ ] Use the free diagnostic link only in pre-paid-GO organic posts.
- [ ] Disclose ownership simply: `È un progetto mio, lo segnalo per trasparenza.`

## Qualification status values

Use only:

- `RESEARCHED — RULES NOT CHECKED`
- `ELIGIBLE — LINK ALLOWED`
- `ELIGIBLE — NO LINK / COMMENT ONLY`
- `ELIGIBLE — PROMO DAY/THREAD ONLY`
- `ADMIN APPROVAL REQUIRED`
- `NOT ELIGIBLE`
- `POSTED`
- `REJECTED/PENDING MODERATION`

Do not write `eligible` from search-engine evidence alone.

# First-wave selection rule

The first wave is **3–5 groups maximum**.

Preferred order once rules are checked:

1. `fb_rip_01` if link/resource posts are allowed.
2. `fb_rip_02` if link/resource posts are allowed.
3. One eligible local parent group found through `fb_search_parent_bo`, `fb_search_parent_mi` or `fb_search_parent_rm`.
4. One eligible local ripetizioni/school-help group found through `fb_search_rip_local`.
5. Use `fb_parent_01` only if its closed-group rules explicitly permit an owned educational resource; otherwise skip it.

Do **not** fill the quota by posting into a group whose rules are unclear.
