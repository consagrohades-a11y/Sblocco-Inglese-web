# Recupero Debito Inglese — Creative Production Package

This file is the production specification for the **same four approved assets only**. A storyboard is not a completed creative. No runtime/application capture should be treated as final until the relevant GO gate is satisfied.

## Brand production constants

Use the current Recovery editorial design as the visual source of truth.

- Navy: `#0E3045`
- Navy soft: `#17465F`
- Orange: `#D34C1A`
- Paper: `#F9F0E8`
- Raised paper: `#FFFAF5`
- Deep paper: `#F1E5DA`
- Display serif stack from the app: `Iowan Old Style`, `Palatino Linotype`, `Book Antiqua`, `Palatino`, `Georgia`, serif.
- Kicker/support UI typography: use the existing app/system sans style. Do not introduce a new decorative font. If the design working file already has a brand sans, use it; otherwise use the platform/system sans stack.
- No purple.
- No green.
- No childish school stickers, mascots, emoji decorations or gaming treatment.
- No fake countdowns or red panic treatment.
- Screenshots must contain **demo data only** and no real learner name, email, school, diagnostic token or account information.

# A1 — 42–44 sec product screen recording

## Deliverable

**Primary master**
- Canvas: `1080 × 1920 px` (9:16).
- Duration: **43.5 seconds**.
- Frame rate: `30 fps`.
- Export: H.264 MP4, high quality, AAC if music is used.
- The video must remain fully understandable muted; no information may depend on audio.

**Capture master**
- Record the real app at **2560 × 1440 px or higher**.
- Browser zoom: `100%`.
- Hide bookmarks bar, extension icons and personal profile UI where possible.
- Keep cursor movement deliberate and slow enough to read; no frantic clicking.

**Required export variants**
1. `A1_recovery_product_9x16_v1.mp4` — 1080×1920.
2. `A1_recovery_product_4x5_v1.mp4` — 1080×1350, same edit recropped; do not create a new narrative.
3. `A1_recovery_product_capture_master.mov/mp4` — archival high-resolution source capture.

## Mobile-safe areas

For the 1080×1920 export, keep every essential overlay, result label and CTA inside:
- horizontal: `x = 90–990`;
- vertical: `y = 250–1600`.

The final URL/CTA must sit between `y = 1350–1570`, never in the lowest 250 px.

For the 1080×1350 derivative, keep essential text inside:
- horizontal: `x = 72–1008`;
- vertical: `y = 90–1240`.

## Overlay hierarchy

- Main hook / key sentence: display serif, `72 px` on 9:16, line-height `0.96`, regular weight.
- Orange emphasis: one short phrase only; use orange `#D34C1A`.
- Supporting line: system sans, `31 px`, weight `650`, line-height `1.25`.
- Small trust line/footer: system sans, `24 px`, weight `650`.
- End-card URL: system sans, `28 px`, weight `800`.

On each shot, use a maximum of **one main line + one small line**. Never stack feature lists over the UI.

## Exact 43.5-second edit

### 0:00–0:03.0 — Hook
**UI:** diagnostic opening screen. Cursor moves once toward `Inizia il test`.

**Overlay:**
`Non ripassare tutto a caso.`

**Crop:** fill the vertical canvas with the central diagnostic card; scale until the card occupies roughly 82–88% of canvas width. Crop browser chrome completely from the final export.

### 0:03.0–0:07.5 — Diagnostic questions
**UI:** show two quick question states; one may briefly show `Non lo so`.

**Overlay:**
`24 domande · circa 6–8 minuti`

**Small line:**
`Prima capisci dove sei.`

**Crop:** keep question prompt and response buttons visible; do not zoom so far that answer text is cut.

### 0:07.5–0:12.5 — Result
**UI:** diagnostic result with the three result groups.

**Overlay:**
`Bene · Da ripassare · Priorità`

**Small line:**
`Non è una previsione del voto.`

**Crop:** centre on the three group headings. If the desktop layout is too wide, use a controlled vertical pan across the three columns; do not show identifying data.

### 0:12.5–0:17.5 — School programme
**UI:** onboarding school year briefly, then topic/programme selection.

**Overlay:**
`Parti dal programma della scuola.`

**Small line:**
`Seleziona solo ciò che ti è stato assegnato.`

**Crop:** prioritise the topic checklist; school-year selector may appear for no more than 1.5 sec.

### 0:17.5–0:22.5 — Exam date → plan
**UI:** exam-date entry, then plan reveal/priority list.

**Overlay:**
`I giorni che restano decidono cosa viene prima.`

**Crop:** show a neutral demo date only. If a date is visible, the account must be clearly demo/test data. The priority list must be readable enough to communicate ordered work.

### 0:22.5–0:28.5 — Recupera → Allenati
**UI:** first Recovery session; show the start of Recupera, then one Allenati task state.

**Overlay:**
`Recupera → Allenati`

**Small line:**
`Un argomento alla volta.`

**Crop:** centre on the active exercise card, not the full application chrome.

### 0:28.5–0:34.0 — Modalità scuola
**UI:** Modalità scuola task format.

**Overlay:**
`Poi prova in Modalità scuola.`

**Crop:** show the task structure and one interaction state; do not expose a long answer sequence or private submission data.

### 0:34.0–0:39.5 — Verifica / targeted next step
**UI:** topic verification/result state or the cleared targeted next step after a weak result.

**Overlay:**
`Verifica l’argomento.`

**Small line:**
`Se resta debole, torna nel lavoro mirato.`

**Crop:** show only a Technical-GO-cleared result/remediation state. Do not show cumulative Readiness v2.

### 0:39.5–0:43.5 — CTA end card
**UI:** navy end card with a faint, low-contrast diagnostic/result crop behind it or no screenshot.

**Main:**
`Fai il test gratuito.`

**Footer:**
`24 domande · 6–8 minuti`

**URL:**
`sbloccoinglese.com/test-recupero-inglese`

**Crop:** none required; this is a designed end card.

## Editing rules

- Hard cuts or 4–6 frame cross-dissolves only; no flashy transitions.
- UI zooms: maximum 108% within a shot.
- No simulated typing except the exam date if needed.
- No screenshots of simulations, cumulative Readiness v2, Stripe checkout or the current sales-page claim blocker.
- Do not label A1 complete until all runtime-dependent shots are captured from the final GO-cleared experience.
